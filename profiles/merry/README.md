# Merry (Meriadoc Brandybuck) — Hermes Profile

Hermes Agent profile styled after **Merry (Meriadoc Brandybuck)** from **Middle-earth: The Fellowship**.

A strategist disguised as a hedonist — someone who uses sociability and humour to earn a seat at tables where serious decisions are made.

Install: `hermes profile install ./<slug>` (see repo README).
